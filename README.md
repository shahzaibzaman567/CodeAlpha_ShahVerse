# ShopSphere 🛍️

A modern full-stack e-commerce platform built with React, Node.js, Express, and MongoDB.

## Features

- User Authentication
- Product Listings
- Product Details Page
- Shopping Cart
- Order Processing
- Admin Product Management
- Responsive Design

## Tech Stack

### Frontend
- React.js
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js
- MongoDB
